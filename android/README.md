# Project 1944 — Android port

This is the private Android port workspace for **Project 1944 / Call of Duty 3**
(Xbox 360 static recompilation). It is a separate repository from the Windows
PC port and is intended for personal use with a legally owned copy of the game.

## Status

**M0b - ReXGlue runtime + Vulkan presenter.**

The APK still does not contain game code and does not run Call of Duty 3. It
proves the full presentation path on the target phone:

```
Android Activity -> SDLActivity -> libmain.so
  -> ReXGlue WindowedApp -> SDL3 window -> VulkanPresenter -> swapchain
```

The app presents a black (cleared) swapchain continuously and logs paint
requests every two seconds. Once M0b is green, the next milestones add the
15 mission modules, touch controls, audio and the actual game.

## ReXGlue SDK patch

`tools/rexglue-source` stays at upstream pin
`0c7b01a0ac0479801757507d80533f662fa0815d`. All Android changes live in a
patch:

```powershell
# after a fresh submodule checkout
.\android\patches\apply-sdk-patch.ps1

# after editing the SDK, regenerate the patch
.\android\patches\export-sdk-patch.ps1
```

Never commit the SDK submodule's modified working tree; commit the patch.

## Requirements

| Component | Version |
|---|---|
| JDK | 17 |
| Android SDK | API 35, build-tools 35.x |
| NDK | 27.3.13750724 |
| CMake | 3.30.5 (SDK copy is fine) |
| Gradle | wrapper 8.10.2 |
| Device | arm64-v8a, Android 9+, Vulkan-capable |

The current machine already has the SDK at `C:\Android\android-sdk` and NDK
`27.3.13750724`. `local.properties` is generated by the build script.

## First build

```powershell
cd C:\Users\runneradmin\Downloads\project-1944-android
.\android\scripts\build-debug.ps1
```

The script:

1. resolves `ANDROID_HOME` / `ANDROID_NDK_HOME`;
2. writes `android/local.properties` if needed;
3. invokes the Gradle wrapper.

APK output:

```
android/app/build/outputs/apk/debug/app-debug.apk
```

## Install and run

```powershell
.\android\scripts\install-debug.ps1
```

Or manually:

```powershell
adb install -r android\app\build\outputs\apk\debug\app-debug.apk
adb shell am start -n com.project1944.cod3/.MainActivity
```

Watch logs:

```powershell
.\android\scripts\logcat.ps1
```

You should see a black screen (a cleared Vulkan swapchain) and log lines
containing `project1944`, the selected Vulkan device and
`paint requests/s`.

## Legal boundary

This repository must never contain:

- `default.xex`, mission XEXs, or any extracted game data;
- generated/recompiled game C++;
- APKs or `.so` files containing game-derived code.

The launcher will verify the user's own `default.xex` before launching. The
private APK is built locally from the user's own disc image.
